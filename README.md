## About

Java/Spring 기반 웹 개발자를 목표로 학습하고 경험을 쌓고 있는 이정하입니다.

- 청운대학교 컴퓨터공학과를 졸업하고 에이콘아카데미 자바 웹개발자 양성과정(클라우드)을 이수했습니다.
- Java, Spring, JSP/Servlet과 데이터베이스를 중심으로 웹 애플리케이션 개발을 학습했습니다. 화면의 요청이 서버 처리와 DB 연동을 거쳐 응답으로 이어지는 흐름에 관심이 있습니다.
- 교육 과정에서 AWS, Docker, Kubernetes와 GitHub Actions를 활용한 배포 및 CI/CD 구성을 학습했습니다.
- 오류가 발생하면 코드뿐 아니라 실행 환경과 데이터 구조를 함께 살피며 원인을 찾습니다. 수정한 뒤에는 연결된 기능이 의도대로 동작하는지 확인합니다.
- 이해되지 않는 부분은 질문하고 문서와 실제 구현이 다르면 확인해 바로잡으려 합니다. 충분히 검토할 부분과 진행하면서 개선할 부분을 구분하는 연습도 하고 있습니다.
- 기능 구현부터 오류 개선까지 책임지고 동료가 이해하고 수정하기 쉬운 코드를 작성하는 개발자로 성장하고 싶습니다.
